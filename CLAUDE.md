# Daily Manna Email - Claude Code Guidelines

## Commit Workflow

**IMPORTANT:** Before creating any commit:
1. Stop and show the commit message to the user
2. Wait for user review/approval
3. Only proceed with commit if approved

Do not auto-commit without user review.

## Branch Strategy

- Work on `feature/email-activity-dashboard`
- Atomic commits following conventional commits format
- Title ≤50 characters (including emoji)
- All tests must pass before committing
